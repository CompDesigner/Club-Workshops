# BMES-Workshops
Contain workshops I led which went over computer vision techniques, embedded system and simulation setups

# Computer Vision
Intro to OpenCV- Introduction to basic computer vision techniques using OpenCV library and Haar Cascade model

Bio-ID- Designed and programmed a simply Biometric ID 

3D Environment Rendering- Generated a 3D Environment Rendering program with HSV color scaling based on distances

# Embedded/Simulation
Medical Sensors Workshop- Wired multiple medical sensors and programmed them to display their given outputs 

UART/I2C Workshop- Wired a range finder design on a breadboard and programmed it to show distance on LCD display

Blood Flow Sim- Used a 3D blood vein/vassel channel to setup plus simulate blood flow
